# Medusa AI Dropship

Production architecture: Medusa commerce + Next.js storefront + OpenAI automation + CJdropshipping integration.

## Core capabilities
- Real Medusa catalog/cart/order/payment/fulfillment modules.
- OpenAI-powered product research, listing generation, customer support and operational recommendations.
- CJ supplier synchronization for real product, price, stock and fulfillment data.
- Strict no-fake-data policy.
- Provider health/status dashboard.

## Important
Software can be self-hosted without a Medusa license fee, but real OpenAI usage, payment processing, domain and infrastructure may have costs. Never represent disconnected providers as live.

Official setup follows current Medusa v2 documentation.
