# AI module

Planned workflows:
1. Discover supplier products from CJ.
2. Score candidates using verified price, stock, shipping and product metadata.
3. Ask OpenAI to generate product titles/descriptions/SEO copy from verified fields only.
4. Create/update Medusa products through workflows.
5. Monitor supplier changes and mark stale products rather than fabricating availability.
6. Provide customer-support drafts grounded in actual order/customer data.

The AI layer must never manufacture reviews, sales, inventory, shipping promises or profitability claims.
